# Sorrow — Releases

Sorrow is a desktop app to conduct your game library: track, rate, review
and complete your backlog. This repository only hosts the Windows releases;
the source code is not public.

## Download

Get the latest installer from the [Releases](../../releases/latest) page:
`Sorrow_<version>_x64-setup.exe`.

- Windows 10 or 11, 64-bit.
- Per-user installation, no administrator rights needed.
- WebView2 is installed automatically if missing (internet connection required).

## Updates

From version 2.1.0, Sorrow updates itself: **About > Update** checks this
repository, shows the release notes and installs the new version on request.
Every update is signed and checked before installation, and the database is
backed up first.

Version 2.0.0 has no built-in updater: install 2.1.0 or later manually once.

## Your data

Your collection is stored locally in
`%APPDATA%\com.noxtibe.backlogsymphony\`. Uninstalling Sorrow keeps it.

# Sorrow — Versions

Sorrow est une application de bureau pour gérer sa ludothèque : suivre, noter,
commenter et terminer son backlog. Ce dépôt ne contient que les versions
Windows ; le code source n'est pas public.

## Télécharger

Prendre le dernier installeur sur la page [Releases](../../releases/latest) :
`Sorrow_<version>_x64-setup.exe`.

- Windows 10 ou 11, 64 bits.
- Installation par utilisateur, sans droits administrateur.
- WebView2 est installé automatiquement s'il manque (connexion internet requise).

## Mises à jour

À partir de la version 2.1.0, Sorrow se met à jour tout seul :
**À propos > Mise à jour** interroge ce dépôt, affiche les notes de version et
installe la nouvelle version à la demande. Chaque mise à jour est signée et
vérifiée avant l'installation, et la base est sauvegardée avant.

La version 2.0.0 n'a pas de mise à jour intégrée : installer une fois la 2.1.0
ou plus récente à la main.

## Vos données

La collection est stockée localement dans
`%APPDATA%\com.noxtibe.backlogsymphony\`. La désinstallation la conserve.
